# QuizZap

Квиз-приложение с таймером, жизнями, системой очков и мультиплеером. Пет-проект по заданию [Quiz App — roadmap.sh](https://roadmap.sh/projects/quiz-app).

**[→ Открыть сайт](https://quiz-zap-pet.vercel.app/)**

---

## О проекте

Несколько квизов на разные темы: динозавры, Смешарики, привидения, погодные явления, ударения в русском языке и разные факты. Вопросы бывают с одним правильным ответом (radio) и несколькими (checkbox).

### Режимы игры

**Одиночная игра:**
- *Обычный* — 5 жизней, 30с на вопрос, 10 баллов за ответ
- *Хардкор* — 3 жизни, 15с на вопрос, 15 баллов за ответ, −5 за ошибку

**Мультиплеер:**
- Хост создаёт комнату и получает короткий код, гости присоединяются по нему или по ссылке
- Все игроки видят один и тот же вопрос одновременно
- 60с на каждый вопрос; результаты (правильные/неправильные варианты и объяснение) открываются только после того, как ответили все
- Очки и таблица лидеров обновляются после каждого вопроса
- Хост управляет темпом: переходит к следующему вопросу, когда готов

### Общие механики

- **Таймер** — таймаут засчитывается как пустой ответ
- **Жизни** — только в одиночных режимах; когда заканчиваются, квиз прерывается
- **Очки** — базовые очки за правильный ответ + бонус за скорость, если ответил достаточно быстро
- **Итоговый экран** — счёт с разбивкой (очки за ответы + бонус), количество правильных ответов и результат (от 💀 до 💎); в мультиплеере — таблица результатов всех участников

## Стек

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript**
- **SASS Modules**
- **Zustand** — глобальный стейт для переключения звука
- **Firebase Realtime Database** — синхронизация состояния комнаты в мультиплеере

## Запуск

```bash
yarn install
yarn dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Для мультиплеера нужен файл `.env.local` с переменными Firebase:

```
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_DATABASE_URL=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...
```

## Добавить квиз

Весь контент — статический. Чтобы добавить новый квиз, достаточно дополнить массив `QUIZZES` в `const/quizData.ts`. Каждый объект квиза содержит `id` (он же slug в URL), `level`, `questions[]`. Тип вопроса — `radio` (один ответ) или `checkbox` (несколько); поле `correct` — массив ID правильных вариантов.
